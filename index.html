Modular Depth Animation for SPS

LumaKroma の VPM 配布リポジトリ

VCC に追加

ALCOM または手動追加では、次の URL をリポジトリ追加欄へ入力してください。

https://lumakroma.github.io/modular-depth-animation/index.json

導入手順

  1. プロジェクトをバックアップして Unity を閉じます。
  2. VRCFury 公式リポジトリを追加してください。VRChat SDK は公式リポジトリを使用します。
  3. 上のボタンから MDA リポジトリを追加。VCC では Settings → Packages → Show Pre-Release Packages を有効にします。ALCOM でもプレリリースを表示してください。
  4. 対象プロジェクトのパッケージ管理で Modular Depth Animation for SPS の 0.1.0-beta.3.rc.1 を選び、変更内容と依存バージョンを確認して導入します。

対応範囲・移行時の注意

検証対象は Unity 2022.3.22f1、VRCFury 本体 1.1470.0、VRChat SDK Base / Avatars 3.10.6。依存バージョンは固定されています。別バージョンのプロジェクトでは変更内容を確認し、不用意にダウングレードしないでください。SPS for NDMF / VRCFury Stub は代用できません。

公開済みの試験済 ZIP を変更せず使用しています。従来の Assets 版 unitypackage と同時導入しないでください。旧版からの移行は未検証で、自動削除・移行は行いません。既存の手動 Packages 版も、まずプロジェクトのコピーでパッケージ管理への切替を確認してください。

配布 ZIP の再導入・生成・保存再読込・SDK preprocess は検証済みです。VCC/ALCOM の画面操作による一連の新規導入・既存導入更新、VRChat 実機動作は未検証です。
